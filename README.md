# Веб-приложение «Судоку»

## Описание проекта

Классическая игра Судоку с выбором сложности, таймером, подсветкой ошибок и сохранением лучшего времени. Приложение разработано на React и TypeScript.

## Установка и запуск

npm install
npm run dev

После запуска приложение будет доступно по адресу: http://localhost:5173

## Сборка проекта

npm run build

## Запуск тестов

npm run test

## Технологический стек

React 18 – библиотека для построения пользовательского интерфейса
TypeScript – статическая типизация
Vite – сборка проекта
Vitest – модульное тестирование
CSS – кастомная стилизация

## Функциональные возможности

Игровое поле 9x9 с разделением на блоки 3x3
Три уровня сложности: Лёгкая, Средняя, Сложная
Таймер, запускающийся при первом действии пользователя
Ввод чисел с клавиатуры (1–9) и удаление (Backspace/Delete)
Подсветка конфликтующих ячеек красным цветом
Сохранение лучшего времени для каждого уровня в localStorage
Модальное окно победы с отображением времени решения
Дизайн в японском стиле с элементами сакуры

## Правила игры

Заполните все пустые ячейки числами от 1 до 9 так, чтобы в каждой строке, каждом столбце и каждом блоке 3x3 все числа встречались ровно один раз. Начальные ячейки выделены серым фоном и не подлежат редактированию.

## Управление

Выберите уровень сложности
Кликните на пустую ячейку – она выделится
Нажмите цифру от 1 до 9 для ввода
Нажмите Backspace или Delete для удаления числа
Нажмите кнопку «Новая игра» для сброса

## Обоснование отказа от дополнительных библиотек

В проекте не используются сторонние библиотеки. Причины:

React Router не требуется, так как приложение одностраничное и не имеет навигации.
Redux или Zustand не нужны, потому что состояние игры локально и управляется через кастомный хук.
UI-киты не используются для сохранения уникального авторского дизайна в японском стиле.
Библиотеки для форм не требуются, так как ввод обрабатывается через события клавиатуры.
Дополнительные утилиты не нужны – все функции реализованы вручную.

## Структура хранения в localStorage

Приложение хранит в localStorage два ключа:

### Ключ `sudoku_best_time`
Содержит объект с лучшим временем (в секундах) для каждого уровня сложности. Значения `easy`, `medium`, `hard` — это лучшее время в секундах.

```json
{
  "easy": 120,
  "medium": 300,
  "hard": 540
}
```

### Ключ `sudoku_history`
Содержит массив последних 10 завершённых игр. Каждый элемент — объект с датой, временем и уровнем сложности.

```json
[
  {
    "date": "13.05.2026, 22:38:20",
    "time": 185,
    "difficulty": "medium"
  },
  {
    "date": "13.05.2026, 21:15:10",
    "time": 320,
    "difficulty": "easy"
  }
]
```
